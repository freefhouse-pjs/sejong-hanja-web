# 세종 한자 공부 — 아이패드용 (iOS 12.5 이상)

안드로이드 앱과 기능이 같고, 학생 기록도 같은 Firebase에 저장됩니다.
앱스토어 앱이 아니라 **Safari의 「홈 화면에 추가」로 설치하는 웹앱**이라서
맥이나 애플 개발자 계정 없이 옛 아이패드(iOS 12)에도 설치할 수 있습니다.

## 1단계: 인터넷에 올리기 (GitHub Pages, 한 번만)
1. https://github.com 로그인 → 오른쪽 위 **+** → **New repository**
   - 이름: `hanja` (아무거나 가능), **Public** 선택 → **Create repository**
     (무료 계정은 Public 저장소만 웹 게시가 됩니다)
2. **uploading an existing file** 클릭
3. 이 폴더 **안의 내용 전체**(index.html, app.js, style.css, config.js, data.js,
   manifest.json, img 폴더, audio 폴더)를 끌어다 놓고 **Commit changes**
4. 저장소 위쪽 **Settings** → 왼쪽 **Pages**
   - Source: **Deploy from a branch** / Branch: **main**, **/(root)** → **Save**
5. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다: `https://아이디.github.io/hanja/`
6. 컴퓨터에서 그 주소를 열어 로그인이 되는지 먼저 확인하세요.

## 2단계: 아이패드에 설치 (기기마다)
1. 아이패드에서 **Safari**로 위 주소를 엽니다. (크롬 등 다른 앱은 안 됨)
2. 주소창 오른쪽 **공유 버튼(네모에 위쪽 화살표)** → **홈 화면에 추가**
3. 이름(세종한자) 확인 → 오른쪽 위 **추가**
4. 홈 화면의 **세종한자** 아이콘으로 실행하면 주소창 없이 앱처럼 전체 화면으로 열립니다.

## 알아 두기
- 인터넷(와이파이)이 연결되어 있어야 로그인·점수 저장이 됩니다.
- 「로그인 정보 저장」을 체크하면 다음부터 [시작하기]만 누르면 됩니다.
- 교사용: 이름에 `교사용` 입력(번호는 아무 숫자) → 학급 결과표, 📋 버튼으로 표 복사
- 소리가 안 나면: 아이패드 옆 스위치(무음)와 음량을 확인하세요.
- 사용 기한(2027년 2월 1일)과 Firebase 프로젝트는 `config.js`에서 바꿀 수 있습니다.

## 고친 내용 다시 올리기
GitHub 저장소에서 바뀐 파일만 다시 **Add file → Upload files**로 올리면 됩니다.
아이패드에 예전 화면이 보이면 앱을 완전히 닫았다가(홈 버튼 두 번 → 위로 밀기) 다시 여세요.
